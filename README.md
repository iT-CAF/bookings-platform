### ‹ جدولة الزواجات والمناسبات بتقويم هجري وميلادي وقواعد حجز عادلة.

منصة لحجز مواعيد الزواجات والحفلات: يسجّل المستخدم ويضيف موعده، ويرى الزائر الجدول بشكل مبسّط مع الحفلة القادمة وعدّاد تنازلي. قواعد الحجز كلها قابلة للضبط من لوحة الإدارة.

</div>

**Wedding & event scheduling with Hijri/Gregorian calendars and fair-booking rules.**

A booking platform for weddings and celebrations. Members sign in and add their date; visitors see a clean public schedule with the next event and a live countdown. Every booking rule is configurable from the admin panel.

## `>` Features · المزايا

| Feature | الميزة |
|:--|--:|
| Hijri & Gregorian calendar | تقويم هجري وميلادي |
| Next event with countdown | الحفلة القادمة مع عدّاد تنازلي |
| Rules: one booking per month, no duplicates, no clashes | قواعد: حجز واحد في الشهر، منع التكرار، منع التعارض |
| Edits and deletions are admin-only after booking | التعديل والحذف للأدمن فقط بعد الحجز |
| Saudi events import: Eids, Ramadan, payroll dates, school calendar | استيراد المناسبات السعودية: الأعياد، رمضان، الرواتب، التقويم الدراسي |

| Layer | Details |
|:--|:--|
